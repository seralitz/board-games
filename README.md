# board.gg

Every skill game. Real stakes. Zero cheating.

## What is board.gg?

board.gg is a competitive gaming platform where you can play any skill game — chess, poker, Go, Tetris, Wordle, backgammon — with real money stakes. 

The only platform where the integrity of every game is guaranteed by Panopticon.

## Compete on everything. Cheat on nothing.

## Powered by Panopticon

Panopticon is the behavioral anti-cheat system that makes real stakes possible. It fingerprints how you play, detects engine assistance, and flags suspicious patterns across multiple games simultaneously.

Without Panopticon, real money competitive gaming is a scam. With it, skill actually wins.
